## Phase 12: Bug Fixes & Polish

**Goal:** All UI bugs and i18n issues from v1.1 are resolved, delivering a polished user experience.

**Dependencies:** None (builds on completed v1.1)

**Requirements:**
- I18N-01: Rating cancel button i18n fix
- NAV-01: Admin link in profile dropdown
- NAV-02: Remove language picker from profile dropdown
- FORM-01: Remove coordinates from add cafe form
- FORM-02: Unified language selection in add cafe form
- LAYOUT-01: My Contributions page header
- LAYOUT-02: My Submissions single header
- LAYOUT-03: Mobile profile no horizontal scroll
- AUTH-01: Photo upload auth detection fix

**Success Criteria:**
1. User sees translated text on rating cancel button (not "common.cancel")
2. Admin user sees admin panel link in profile dropdown menu
3. User adding a cafe enters address only (no coordinates field visible)
4. User on My Contributions page sees proper page header
5. User on mobile profile page can scroll vertically without horizontal overflow
