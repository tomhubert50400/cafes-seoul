  <files>supabase/migrations/0901_photos_voting.sql</files>
  <action>
Continue the same migration file:

1. Enable RLS on photos and photo_votes tables

2. Photos RLS policies:
   - SELECT: Anyone can view APPROVED photos only (status = 'approved')
   - SELECT: Users can view their OWN photos regardless of status
   - SELECT: Admins can view ALL photos
   - INSERT: Authenticated users can insert (validation in app layer)
   - UPDATE: Only admins can update status, rejection_reason
   - DELETE: Users can delete their OWN pending photos only

3. Photo votes RLS policies:
   - SELECT: Anyone can view votes (for count display)
   - INSERT: Users can only vote for themselves (user_id = auth.uid())
   - DELETE: Users can only delete their own votes

4. Create trigger function to auto-update photos.upvote_count when votes change:
   - ON INSERT/DELETE on photo_votes: recalculate upvote_count for affected photo
   - Use SECURITY DEFINER to bypass RLS

5. Add updated_at trigger for photos table
