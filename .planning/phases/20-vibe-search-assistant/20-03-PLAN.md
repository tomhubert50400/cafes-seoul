The cafes list page (`/cafes`) uses URL search params for filter state, NOT the useMapFilters hook. The PresetBadges component needs to be wired differently here.

**IMPORTANT LIMITATION:** The cafes list page API only supports boolean feature filters (hasWifi, hasOutlets, isPetFriendly, isLaptopFriendly, hasParking) via URL params. It does NOT support per-dimension rating filters (wifiMin, quietnessMin, etc.). This means:
- `work_study` preset has 2 boolean filters (hasPowerOutlets, isLaptopFriendly) + 3 rating dims (rating dims ignored on list page)
- `aesthetic_date` preset has ZERO boolean filters (only rating dims) -- on the list page, selecting this clears all filters
- `quick_stop` preset has ZERO boolean filters (only rating dims) -- on the list page, selecting this clears all filters

**The approach:** Accept this limitation gracefully. All presets function as "apply my boolean subset + clear everything else." Preset highlighting on the list page only works for presets that have boolean filters. Presets with no boolean filters (aesthetic_date, quick_stop) act as "clear all" and do NOT highlight, since the list page cannot distinguish between them. The full vibe experience (with rating dimensions) is available on the map page.

In `src/components/search-filters.tsx`:

1. Import the needed modules:

2. Create a helper constant (outside the component or as a module-level const) that identifies which boolean MapFilters keys map to which URL param names:
```typescript
const BOOLEAN_FILTER_MAP: Record<string, string> = {
  hasWifi: 'hasWifi',
  hasPowerOutlets: 'hasOutlets',
  isPetFriendly: 'isPetFriendly',
  isLaptopFriendly: 'isLaptopFriendly',
  hasParking: 'hasParking',
};
```

3. Create a preset selection handler inside the component:
```typescript
const handlePresetSelect = useCallback((presetId: string) => {
  const preset = FILTER_PRESETS.find(p => p.id === presetId);
  if (!preset) return;

  // Build new URL params from preset's boolean filters only
  const params = new URLSearchParams();

  // Apply only boolean filters from the preset
  for (const [filterKey, urlParam] of Object.entries(BOOLEAN_FILTER_MAP)) {
    if (preset.filters[filterKey as keyof typeof preset.filters] === true) {
      params.set(urlParam, 'true');
    }
  }

  // Preserve current sort preference
  const currentSort = searchParams.get('sortBy');
  if (currentSort) params.set('sortBy', currentSort);

  router.push(`?${params.toString()}`);
}, [router, searchParams]);
```

4. Compute the matched preset from current URL params:
```typescript
const matchedPresetId = useMemo(() => {
  // Read current boolean filter state from URL
  const currentBooleans: Record<string, boolean> = {};
  for (const [filterKey, urlParam] of Object.entries(BOOLEAN_FILTER_MAP)) {
    currentBooleans[filterKey] = searchParams.get(urlParam) === 'true';
  }

  // Check for extra non-preset URL params (district, cafeType, search query)
  const hasExtraFilters = !!(
    searchParams.get('district') ||
    searchParams.get('cafeType') ||
    searchParams.get('q')
  );
  if (hasExtraFilters) return null;

  for (const preset of FILTER_PRESETS) {
    // Extract which boolean keys this preset defines
    const presetBooleanKeys = Object.keys(BOOLEAN_FILTER_MAP).filter(
      key => preset.filters[key as keyof typeof preset.filters] === true
    );

    // Skip presets that have NO boolean filters -- they cannot be
    // meaningfully distinguished on the list page. These presets
    // (aesthetic_date, quick_stop) work as "clear all" on click
    // but never highlight, since the list page can't apply their
    // rating-dimension filters.
    if (presetBooleanKeys.length === 0) continue;

    // Check: all preset booleans are ON in URL
    const presetBooleansMatch = presetBooleanKeys.every(
      key => currentBooleans[key] === true
    );

    // Check: no EXTRA booleans are ON beyond what preset defines
    const extraBooleansOff = Object.keys(BOOLEAN_FILTER_MAP)
      .filter(key => !presetBooleanKeys.includes(key))
      .every(key => currentBooleans[key] === false);

    if (presetBooleansMatch && extraBooleansOff) {
      return preset.id;
    }
  }

  return null;
}, [searchParams]);
```
