<task type="auto">
  <name>Task 1: Add viewport metadata and fix root layout</name>
  <files>src/app/layout.tsx</files>
  <action>
    Add the Next.js viewport export to the root layout:

    ```tsx
    import type { Viewport } from 'next'

    export const viewport: Viewport = {
      width: 'device-width',
      initialScale: 1,
      maximumScale: 5,
      userScalable: true,
    }
    ```

    Place the export AFTER the existing `metadata` export. Do NOT set `maximumScale: 1` or `userScalable: false` as that violates WCAG accessibility guidelines.

    Also add `overflow-x-hidden` to the body element to prevent any horizontal scroll from child elements at the global level:
    ```tsx
    <body className={`... overflow-x-hidden`}>
    ```
  </action>
  <verify>Run `npx next build` (or `npm run build`) and confirm no TypeScript errors. Check that the viewport export is recognized by searching for "export const viewport" in the file.</verify>
  <done>Root layout exports viewport metadata with device-width, initialScale 1, maximumScale 5, userScalable true. Body has overflow-x-hidden.</done>
</task>
