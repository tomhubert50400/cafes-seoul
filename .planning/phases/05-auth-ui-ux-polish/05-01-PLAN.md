## Current State
Both forms already use react-hook-form with `mode: 'onBlur'` which aligns with requirements. However, they don't:
1. Clear errors immediately when user starts typing in an invalid field
2. Auto-focus the first invalid field on validation failure
3. Re-validate on blur after user corrects an error

## Requirements from Context
- **Timing:** Errors appear on field blur, not while typing or only on submit
- **Display:** Inline below each field with clear error text
- **Re-validation:** For fields that already showed errors, clear the error immediately when user starts typing, then re-validate on next blur
- **Focus management:** On validation error, automatically focus the first invalid field
</context>
