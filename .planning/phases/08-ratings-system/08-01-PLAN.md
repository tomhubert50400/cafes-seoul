## Patterns from Phase 7

**Database Pattern (from 0701_cafe_submissions.sql):**
- Use CREATE TYPE IF NOT EXISTS for enums
- Tables with IF NOT EXISTS, timestamps with DEFAULT now()
- RLS policies: SELECT for all, INSERT/UPDATE/DELETE for authenticated owners
- Row-level security with USING (user_id = auth.uid())
- Helper functions for computed values
- Indexes on foreign keys and commonly filtered columns
- ON DELETE CASCADE for relationships

**Type Pattern (from src/types/submission.ts):**
- Interface for database entity (e.g., UserRating)
- Interface for input (e.g., RatingInput)
- Type for dimension keys/labels
- JSDoc comments explaining fields
- Optional joined data fields (user?, cafe?)

**Transform Pattern (from transforms.ts):**
- Function named transform[EntityName] with row: Record<string, unknown>
- ParseFloat for numeric fields from database
- Null handling for optional fields
- Typed return value

Create comprehensive database migration for cafe ratings system:

**Table: cafe_ratings**
- id: uuid primary key default gen_random_uuid()
- user_id: uuid NOT NULL references profiles(id) on delete cascade
- cafe_id: uuid NOT NULL references cafes(id) on delete cascade
- overall: integer NOT NULL CHECK (overall >= 1 AND overall <= 5) -- mandatory
- coffee: integer CHECK (coffee >= 0 AND coffee <= 5) DEFAULT 0 -- optional, 0 = not rated
- wifi: integer CHECK (wifi >= 0 AND wifi <= 5) DEFAULT 0
- price_value: integer CHECK (price_value >= 0 AND price_value <= 5) DEFAULT 0
- quietness: integer CHECK (quietness >= 0 AND quietness <= 5) DEFAULT 0
- seating: integer CHECK (seating >= 0 AND seating <= 5) DEFAULT 0
- comfort: integer CHECK (comfort >= 0 AND comfort <= 5) DEFAULT 0
- food: integer CHECK (food >= 0 AND food <= 5) DEFAULT 0
- pet_friendly: boolean DEFAULT false
- lighting: integer CHECK (lighting >= 0 AND lighting <= 5) DEFAULT 0 -- mapped from ambiance
- outlets: integer CHECK (outlets >= 0 AND outlets <= 5) DEFAULT 0
- timestamps: created_at, updated_at with DEFAULT now()

**Constraints:**
- UNIQUE(user_id, cafe_id) - one rating per user per cafe (upsert)
- RLS enabled

**Indexes:**
- cafe_id for aggregation queries
- user_id for user's ratings list
- Composite (cafe_id, overall) for filtering

**RLS Policies:**
- SELECT: authenticated users can read all ratings
- INSERT: authenticated users can only insert their own (user_id = auth.uid())
- UPDATE: authenticated users can only update their own
- DELETE: authenticated users can only delete their own (for data cleanup)

**Helper Function:**
- upsert_cafe_rating(user_uuid, cafe_uuid, rating_data JSONB) - handles insert/update with timestamp

**Update Cafe Averages Trigger (optional but recommended):**
- Function to update cafes.overall_rating and cafes.total_ratings when rating changes
- Exclude 0 values from average calculation (RATE-04 requirement)

Follow Phase 7 migration patterns: IF NOT EXISTS guards, proper comments, consistent naming.

export function transformUserRating(row: Record<string, unknown>): UserRating {
  const user = row.profiles as Record<string, unknown> | null;
  const cafe = row.cafes as Record<string, unknown> | null;

  return {
    id: row.id as string,
    userId: row.user_id as string,
    cafeId: row.cafe_id as string,
    overall: parseInt(row.overall as string, 10) || 0,
    coffee: parseInt(row.coffee as string, 10) || 0,
    wifi: parseInt(row.wifi as string, 10) || 0,
    priceValue: parseInt(row.price_value as string, 10) || 0,
    quietness: parseInt(row.quietness as string, 10) || 0,
    seating: parseInt(row.seating as string, 10) || 0,
    comfort: parseInt(row.comfort as string, 10) || 0,
    food: parseInt(row.food as string, 10) || 0,
    petFriendly: row.pet_friendly as boolean || false,
    lighting: parseInt(row.lighting as string, 10) || 0,
    outlets: parseInt(row.outlets as string, 10) || 0,
    createdAt: row.created_at as string,
    updatedAt: row.updated_at as string,
    user: user ? transformRatingUser(user) : undefined,
    cafe: cafe ? transformRatingCafe(cafe) : undefined,
  };
}
