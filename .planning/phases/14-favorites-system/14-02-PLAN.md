Create client component following RESEARCH.md Pattern 1 (useOptimistic) and Pattern 3 (Framer Motion bounce):

```typescript
'use client';

import { useState, useOptimistic, useTransition } from 'react';
import { Heart } from 'lucide-react';
import { motion } from 'framer-motion';
import { toast } from 'sonner';
import { cn } from '@/lib/utils';
import { toggleFavoriteAction } from '@/lib/actions/favorites';
```

**Props interface:**
```typescript
interface FavoriteButtonProps {
  cafeId: string;
  initialIsFavorited: boolean;
  size?: 'sm' | 'md' | 'lg';
  className?: string;
}
```

**Implementation details:**
1. Use `useState` for actual favorited state (synced with server)
2. Use `useOptimistic` for immediate UI feedback
3. Use `useTransition` with `startTransition` to wrap async operation
4. Disable button while `isPending` to prevent race conditions

**Click handler:**
- Prevent event propagation (`e.preventDefault()`, `e.stopPropagation()`) since button is inside Link
- Call `setOptimisticIsFavorited(!optimisticIsFavorited)` inside startTransition
- Call `toggleFavoriteAction(cafeId)`
- On success: `setIsFavorited(result.isFavorited)`
- On error: toast.error, optimistic update auto-reverts

**Animation:**
- `whileTap={{ scale: 0.9 }}` for press feedback
- `animate={{ scale: justToggled ? [1, 1.2, 1] : 1 }}` for bounce
- Track `justToggled` state to prevent animation on initial render (RESEARCH.md Pitfall 4)
- Spring transition: `stiffness: 500, damping: 15`

**Styling:**
- Filled red (`fill-red-500 text-red-500`) when favorited
- Outline (`text-muted-foreground`) when not
- Size variants: sm (h-4 w-4), md (h-5 w-5), lg (h-6 w-6)
- Semi-transparent background for visibility on images: `bg-background/80 rounded-full p-1.5`
