Create Server Actions following established patterns:

1. updateReviewTextAction:
```typescript
'use server';

export async function updateReviewTextAction(
  ratingId: string,
  reviewText: string
): Promise<UpdateReviewTextResult>
```
- Verify authentication (getUser)
- Validate with reviewTextSchema
- Call updateReviewText(supabase, ratingId, user.id, reviewText || null)
- If reviewText is empty/null, delete all helpful votes for this rating
- Revalidate: `/profile/reviews`, get cafe slug and revalidate `/cafes/[slug]`
- Return { success: true } or { success: false, error }

2. deleteReviewTextAction (convenience wrapper):
```typescript
export async function deleteReviewTextAction(
  ratingId: string
): Promise<UpdateReviewTextResult>
```
- Calls updateReviewTextAction with empty string
- Confirmation dialog is in UI, not server

3. toggleHelpfulAction:
```typescript
export async function toggleHelpfulAction(
  ratingId: string
): Promise<ToggleHelpfulResult>
```
- Verify authentication
- Check if rating belongs to user (cannot vote own review):
  - Query cafe_ratings.user_id where id = ratingId
  - If user_id === current user, return { success: false, error: 'Cannot vote on own review' }
- Check if review has text (no voting on rating-only):
  - Query cafe_ratings.review_text where id = ratingId
  - If review_text is null, return { success: false, error: 'Review has no text' }
- Call toggleHelpfulVote(supabase, user.id, ratingId)
- Revalidate cafe page (get cafe_id from rating, then slug)
- Return result with isVoted boolean

4. getCafeReviewsAction:
```typescript
export async function getCafeReviewsAction(
  cafeId: string
): Promise<{ success: boolean; reviews?: ReviewWithAuthor[]; error?: string }>
```
- Get current user ID (may be null for non-logged-in)
- Call getCafeReviewsWithVotes(supabase, cafeId, userId)
- Return { success: true, reviews }
