<task type="auto">
  <name>Task 2: Create Zod validation schemas for auth forms</name>
  <files>src/lib/validations/auth.ts</files>
  <action>
Create `src/lib/validations/auth.ts` with Zod schemas for signup and login forms.

**signupSchema:**
- email: required, valid email format
- password: min 8 chars (matches Supabase default requirement)

**loginSchema:**
- email: required, valid email format
- password: required (no length check - that's signup only)

Export both schemas and their inferred TypeScript types.

Example structure:
```typescript
import { z } from 'zod'

export const signupSchema = z.object({
  email: z.string().min(1, 'Email is required').email('Invalid email address'),
  password: z.string().min(8, 'Password must be at least 8 characters'),
})

export const loginSchema = z.object({
  email: z.string().min(1, 'Email is required').email('Invalid email address'),
  password: z.string().min(1, 'Password is required'),
})

export type SignupInput = z.infer<typeof signupSchema>
export type LoginInput = z.infer<typeof loginSchema>
```

Note: Do NOT add complex password rules (uppercase, number, etc.) - research shows Supabase default is just min 8 chars. The password strength meter provides guidance, not enforcement.
