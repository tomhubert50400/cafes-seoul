Create `src/app/actions/auth.ts` with Server Actions for all auth operations.

**signup(prevState, formData):**
1. Validate input with signupSchema
2. Call supabase.auth.signUp with emailRedirectTo pointing to /auth/confirm
3. On error: return { message, errors } object
4. On success: redirect('/') - toast handled on client

**login(prevState, formData):**
1. Validate input with loginSchema
2. Call supabase.auth.signInWithPassword
3. Map Supabase errors:
   - "Invalid login credentials" -> "Invalid email or password"
   - "Email not confirmed" -> return { message, showResend: true, email } for resend UI
4. On success: redirect('/')

**logout():**
1. Call supabase.auth.signOut()
2. redirect('/login')

**resendVerification(email: string):**
1. Call supabase.auth.resend({ type: 'signup', email, options: { emailRedirectTo } })
2. Return { success: true } or { error: message }

Important patterns:
- Use 'use server' directive at top
- Import createClient from '@/lib/supabase/server'
- Import schemas from '@/lib/validations/auth'
- Use redirect() from 'next/navigation' (not return)
- Return error objects, don't throw (enables better UX)
- CRITICAL: Use getUser() not getSession() in any server code (security)

Email redirect URL: `${process.env.NEXT_PUBLIC_APP_URL}/auth/confirm`

Create `src/app/auth/confirm/route.ts` as a Route Handler for email verification.

This handles the email verification link when users click "Confirm Email" in their inbox.

**GET handler:**
1. Extract token_hash and type from searchParams
2. If present, call supabase.auth.verifyOtp({ type, token_hash })
3. On success: redirect to '/' (user is now logged in via cookie)
4. On error: redirect to '/login?error=Unable to verify email'

The Supabase email template must be configured to use:
`{{ .SiteURL }}/auth/confirm?token_hash={{ .TokenHash }}&type=email`

(This is a dashboard configuration, not code - just document it in the action.)

Example:
```typescript
import { createClient } from '@/lib/supabase/server'
import { NextRequest, NextResponse } from 'next/server'

export async function GET(request: NextRequest) {
  const { searchParams } = new URL(request.url)
  const token_hash = searchParams.get('token_hash')
  const type = searchParams.get('type')

  if (token_hash && type) {
    const supabase = await createClient()
    const { error } = await supabase.auth.verifyOtp({
      type: type as 'email' | 'signup',
      token_hash,
    })

    if (!error) {
      return NextResponse.redirect(new URL('/', request.url))
    }
  }

  return NextResponse.redirect(
    new URL('/login?error=Unable to verify email', request.url)
  )
}
```
