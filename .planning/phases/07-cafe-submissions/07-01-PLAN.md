**Phase 7 Goal:** Users can propose new cafes with validation and approval workflow

**Requirements Covered:**
- SUBMIT-01: Submit with name and address
- SUBMIT-02: Optional phone number

  <name>Task 1: Create database migration for cafe submissions</name>
  <files>supabase/migrations/0701_cafe_submissions.sql</files>
  <action>
Create a comprehensive database migration file that establishes the cafe submission system.

**Tables to create:**

1. **user_roles enum** (if not exists):
   - VALUES: 'user', 'pro', 'admin'
   - Add role column to public.users table with default 'user'

2. **cafe_submissions table**:
   - id: uuid PRIMARY KEY DEFAULT gen_random_uuid()
   - user_id: uuid NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE
   - name: jsonb NOT NULL (translated names: {en, ko, fr, zh, vi})
   - address: jsonb NOT NULL (translated addresses)
   - phone: text (nullable, optional)
   - latitude: numeric (nullable, for geolocation)
   - longitude: numeric (nullable, for geolocation)
   - district_id: integer (nullable, references districts)
   - neighborhood_id: integer (nullable, references neighborhoods)
   - status: submission_status NOT NULL DEFAULT 'pending'
     - submission_status enum: 'pending', 'approved', 'declined'
   - rejection_reason: text (nullable, for declined submissions)
   - admin_notes: text (nullable, for admin internal use)
   - created_at: timestamptz DEFAULT now()
   - updated_at: timestamptz DEFAULT now()
   - approved_at: timestamptz (nullable)
   - approved_by: uuid (nullable, references auth.users)
   - cafe_id: uuid (nullable, references cafes, populated on approval)

3. **submission_rate_limits table**:
   - user_id: uuid PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE
   - submission_count: integer DEFAULT 0
   - reset_at: timestamptz NOT NULL (when daily limit resets)
   - last_submission_at: timestamptz (nullable)

**Indexes to create:**
- cafe_submissions(user_id, status) - for user's submissions list
- cafe_submissions(status, created_at) - for admin moderation queue
- cafe_submissions(created_at DESC) - for recent submissions

**RLS Policies:**
- cafe_submissions:
  - SELECT: Users can see their own submissions OR admins can see all
  - INSERT: Authenticated users can insert (rate limiting enforced in app layer)
  - UPDATE: Users can update their own pending submissions OR admins can update any
  - DELETE: Users can delete their own pending submissions

**Functions/Triggers:**
- update_updated_at() trigger function (if not exists)
- Trigger to auto-update updated_at on cafe_submissions

**NOTES:**
- Do NOT create the submission_status enum if it already exists (use CREATE TYPE IF NOT EXISTS)
- Use jsonb for translated fields (matches existing cafe.name/address pattern)
- Use numeric for lat/lng (matches cafe table)
- Add helpful comments on each table/column for documentation
