       a. **Input Processing**:

       b. **Search Logic**:
          - Query the `cafes` table (approved cafes) for potential duplicates

       c. **Return Structure**:

          - `id` (uuid): Cafe ID
          - `name` (text): Cafe name
          - `address` (text): Cafe address  
          - `similarity_score` (real): Similarity score (0.0 to 1.0)
          - `match_type` (text): 'name' or 'name_address'

       d. **Ranking**:
          - Order by similarity_score DESC
          - Limit results (e.g., top 5 matches)

    3. **Security**:
       - Function should be SECURITY DEFINER or have appropriate grants
       - Should be accessible to authenticated users

    4. **Example Implementation Pattern**:
       ```sql
       CREATE OR REPLACE FUNCTION find_duplicate_cafes(
         p_name text,
         p_address text
       )
       RETURNS TABLE (
         id uuid,
         name text,
         address text,
         similarity_score real,
         match_type text
       )
       LANGUAGE plpgsql
       SECURITY DEFINER
       AS $$
       BEGIN
         -- Handle JSON-wrapped inputs
         DECLARE
           v_name text;
           v_address text;
         BEGIN
           -- Try to parse as JSON first, fallback to raw text
           BEGIN
             v_name := p_name::jsonb ->> 0;
           EXCEPTION WHEN OTHERS THEN
             v_name := p_name;
           END;
           
           BEGIN
             v_address := p_address::jsonb ->> 0;
           EXCEPTION WHEN OTHERS THEN
             v_address := p_address;
           END;
         END;

         RETURN QUERY
         SELECT 
           c.id,
           c.name,
           c.address,
           similarity(c.name, v_name) as similarity_score,
           CASE 
             WHEN similarity(c.address, v_address) > 0.5 THEN 'name_address'::text
             ELSE 'name'::text
           END as match_type
         FROM cafes c
         WHERE similarity(c.name, v_name) > 0.3
         ORDER BY similarity(c.name, v_name) DESC
         LIMIT 5;
       END;
       $$;
       ```

    5. **Grants**:

       ```sql
       GRANT EXECUTE ON FUNCTION find_duplicate_cafes(text, text) TO anon;
       ```
