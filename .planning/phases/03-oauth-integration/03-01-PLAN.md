<task type="auto">
  <name>Task 1: Create OAuth callback route handler</name>
  <files>src/app/auth/callback/route.ts</files>
  <action>
Create the OAuth callback route handler at `/auth/callback` that:

1. Extracts `code`, `next`, `error`, and `error_description` from searchParams
2. Handles provider errors (user cancellation = `access_denied`, other errors):
   - User cancellation: redirect to `/login?error=Login cancelled`
   - Other errors: redirect with error_description or generic message
3. If code exists, call `supabase.auth.exchangeCodeForSession(code)`
4. On success: redirect to `next` param (default `/`), validate that next starts with `/` to prevent open redirect
5. On exchange error: map error codes to user-friendly messages:
   - `flow_state_expired`: "Login took too long. Please try again."
   - `bad_oauth_state`: "Login session expired. Please try again."
   - Default: "OAuth authentication failed"
6. No code and no error: redirect to `/login`

Use the pattern from RESEARCH.md. Import `createClient` from `@/lib/supabase/server`.
  </action>

  </verify>

<task type="auto">
  <name>Task 2: Add OAuth login server action</name>
  <files>src/app/actions/auth.ts</files>
  <action>
Add `loginWithOAuth` server action to the existing auth.ts file:

1. Define `OAuthProvider` type as `'google' | 'kakao'`
2. Create async function `loginWithOAuth(provider: OAuthProvider, next?: string)` that:
   - Returns `{ url: string } | { error: string }`
   - Uses `createClient` from `@/lib/supabase/server`
   - Builds redirectTo URL: `${process.env.NEXT_PUBLIC_APP_URL}/auth/callback` with optional `next` param
   - Calls `supabase.auth.signInWithOAuth({ provider, options: { redirectTo } })`
   - On error: map `provider_disabled` to provider-specific message, else generic "Unable to start login"
   - On success: return `{ url: data.url }` for client-side redirect
3. Export the function and type

Note: Server Actions cannot redirect to external URLs, so we return the URL for the client to handle.
  </action>
