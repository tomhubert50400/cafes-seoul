# Milestone v1.5: Vibe Search

**Status:** SHIPPED 2026-02-07
**Phases:** 20
**Total Plans:** 3

## Overview

Smart filter presets ("vibes") that let users quickly find cafes matching common use-cases (work/study, date/aesthetic, quick stop) without manually configuring 9+ filter dimensions.

## Phases

### Phase 20: Vibe Search Assistant

**Goal:** Let users quickly find cafes matching common use-cases without manually configuring 9+ filter dimensions.
**Depends on:** None (v1.4 shipped)
**Plans:** 3 plans

Plans:
- [x] 20-01-PLAN.md — Preset definitions, matching logic, and i18n translations
- [x] 20-02-PLAN.md — Hook extension and PresetBadges UI component
- [x] 20-03-PLAN.md — Integration into map, cafes list, and roulette pages

**Success criteria:**
- Preset badges available in filter panels on /cafes, /map, and roulette pages
- Selecting a preset applies correct filter values to existing filter system
- Users can modify individual filters after preset selection
- Visual indicator shows when filters match a known preset
- i18n support for preset labels (ko/en/fr/zh/vi)

## Milestone Summary

**Key Decisions:**
- Inline DEFAULT_FILTER_VALUES to avoid circular dependency between filter-presets.ts and use-map-filters.ts
- Shallow field comparison + extra-filter detection for preset matching
- Collapsible PresetBadges hidden by default (user feedback)
- flex-wrap instead of horizontal scroll for badge layout (user feedback)
- Presets inside filter sheets, not on page surface (user feedback)
- Preset toggle: clicking active preset deselects it (user feedback)
- Full MapFiltersPanel sheet on cafes list page with 9 server-side rating filters

**Issues Resolved:**
- TS2448 block-scoped variable used before declaration (reordered declarations)
- Badge overflow on narrow viewports (switched to flex-wrap)
- Preset discoverability vs UI clutter (collapsible with +/- toggle)

**Issues Deferred:**
- None

**Technical Debt Incurred:**
- Slight duplication of DEFAULT_FILTER_VALUES between filter-presets.ts and use-map-filters.ts (avoids circular dep)
