# Milestone v1.3: Profile Enhancement

**Status:** SHIPPED 2026-02-01
**Phases:** 13-18
**Total Plans:** 25

## Overview

Enhance user profile with reviews, favorites, and comprehensive settings. Users can view their rating history, save favorite cafes, customize their profile, reset passwords, manage notification preferences, and receive email updates on submission status changes.

## Phases

**Goal**: User can view their complete rating history with cafe details

**Plans**: 3 plans

Plans:

## Milestone Summary

**Key Decisions:**
- Dimension labels in utility file for programmatic access
- Check-then-act pattern for favorite toggle (RLS constraint)
- ID-based public profile route (more stable than username)
- Extend cafe_ratings vs separate reviews table (simpler queries)
- Password min score 2 (Good) balancing security and UX
- AFTER triggers prevent blocking admin actions
- Table-based HTML email layouts for client compatibility
- Opt-out notification model (enabled by default)

**Issues Resolved:**
- Mobile overflow in ReviewCard layout
- Profile FK constraint error (separate profile fetch)
- Wrong column name for privacy check (is_private vs profile_public)
- Missing username fallback in ReviewAuthor type

**Issues Deferred:**
- TXT-02: Review titles - deferred to future milestone

**Technical Debt Incurred:**
- Phase 18 missing formal VERIFICATION.md (verified via E2E testing)
