# Requirements: Cafes Seoul — Milestone v1.1

**Defined:** 2026-01-30
**Milestone:** v1.1 User Contributions
**Core Value:** Filtrage multi-critères avec notes 1-5 sur chaque dimension du café

## v1.1 Requirements

### Cafe Submissions

- [x] **SUBMIT-01**: User can submit a new cafe with name and address (required)
- [x] **SUBMIT-02**: User can optionally provide phone number
- [x] **SUBMIT-03**: System shows potential duplicates before allowing submission
- [x] **SUBMIT-04**: Submission is pending admin approval before appearing on site
- [x] **SUBMIT-05**: User can edit submission while pending
- [x] **SUBMIT-06**: User can delete submission while pending
- [ ] **SUBMIT-07**: User receives notification when submission is approved/rejected — DEFERRED to v2
- [x] **SUBMIT-08**: Rate limit: 3 cafe submissions per user per day

### Cafe Ratings

- [x] **RATE-01**: User must provide overall rating (1-5) when rating a cafe
- [x] **RATE-02**: User can optionally rate on 9 additional dimensions (0-5, 0 = not rated)
- [x] **RATE-03**: User can indicate if cafe is pet friendly (boolean)
- [x] **RATE-04**: Ratings of 0 do not impact the average calculation
- [x] **RATE-05**: User can update their ratings anytime (overwrite previous)
- [x] **RATE-06**: Cafe cards show average rating as stars with review count
- [x] **RATE-07**: Rate button appears on cafe list cards, map info windows, and detail page
- [x] **RATE-08**: No rate limit (unlimited ratings)

### Photos

- [x] **PHOTO-01**: User can upload photos to any approved cafe
- [x] **PHOTO-02**: Limit: 3 photos per user per cafe
- [x] **PHOTO-03**: Rate limit: 10 photo uploads per user per day
- [x] **PHOTO-04**: Photos require separate admin approval from cafe approval
- [x] **PHOTO-05**: Approved photos are visible on cafe detail page gallery
- [x] **PHOTO-06**: Photos display in order of most upvoted
- [x] **PHOTO-07**: User cannot delete photos after approval (admin only)

### Photo Voting

- [x] **VOTE-01**: User can upvote photos with heart button
- [x] **VOTE-02**: One upvote per user per photo
- [x] **VOTE-03**: Photos sorted by upvote count (highest first)

### Admin Panel

- [x] **ADMIN-01**: Admin can view list of pending cafe submissions
- [x] **ADMIN-02**: Admin can approve cafe submissions
- [x] **ADMIN-03**: Admin can reject cafe submissions with reason
- [x] **ADMIN-04**: Admin can edit submission details before approving
- [x] **ADMIN-05**: Admin can view list of pending photos
- [x] **ADMIN-06**: Admin can approve/reject photos
- [x] **ADMIN-07**: Role-based access control (user/pro/admin)

### User Dashboard

- [x] **DASH-01**: User can view their submitted cafes (pending/approved counts)
- [x] **DASH-02**: User can view their ratings given
- [x] **DASH-03**: User can view their uploaded photos
- [x] **DASH-04**: Dashboard shows contribution statistics

### Roles System

- [x] **ROLE-01**: Users have `user` role by default
- [x] **ROLE-02**: `pro` role exists (reserved for future cafe owner features)
- [x] **ROLE-03**: `admin` role has full moderation access
- [x] **ROLE-04**: Only users with `admin` role can access admin panel
